## 0.1.0 (2025-01-XX)

### 🚀 Features

- Initial release of Vincent Ability Aave
- Support for supply, borrow, withdraw, and repay operations on Aave protocol
- Support for multiple chains: Ethereum, Arbitrum, Base, Polygon, Optimism, Avalanche, BSC, and CoreDAO
- Automatic ERC20 approval handling for supply and repay operations
- Optional Alchemy gas sponsorship (EIP-7702)
- Comprehensive precheck validation for all operations
- Gas estimation support for non-sponsored transactions

- @lit-protocol/vincent-scaffold-sdk: ^1.1.7
- ethers: ^5.8.0

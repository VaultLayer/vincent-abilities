## 0.1.0 (2025-10-24)

### 🚀 Features

- Initial release of Call Contract Ability
- Support for calling any smart contract function
- Support for standard function arguments and base64-encoded complex tuples
- Optional gas sponsorship via Alchemy EIP-7702
- Support for appending custom call data
- Multi-chain support for EVM-compatible networks
- Integration with Call Contract Whitelist Policy

### 📝 Documentation

- Added comprehensive README with usage examples
- Added CONTRIBUTING guide

### 🔄 Migration

- Ported from @lit-protocol/aw-tool-vl-call-contract with backward-compatible parameters
- Migrated to Vincent authentication and delegation system
- Added new Alchemy gas sponsorship support
